# Анализ лояльности пользователей Яндекс Афиши

Учебный проект Яндекс Практикума по модулю Python.

## Цель проекта

Изучить факторы, влияющие на возврат пользователей на платформу Яндекс Афиша, и определить характеристики пользователей с высокой вероятностью повторных покупок.

## Используемые инструменты

* Python
* Pandas
* Matplotlib
* Seaborn
* SQL
* PostgreSQL
* PhiK

## Основные результаты

* Построен профиль пользователя на основе истории заказов.
* Проанализировано влияние типа мероприятия, устройства, региона и билетного оператора на возврат пользователей.
* Исследована связь между выручкой, количеством билетов и повторными покупками.
* Выполнен корреляционный анализ факторов, связанных с количеством заказов.

## Структура проекта

* `ds_final_module_project_afisha.ipynb` - основной ноутбук с анализом.
* `final_tickets_tenge_df.csv` - данные по курсам тенге.
* `requirements.txt` - используемые библиотеки.
